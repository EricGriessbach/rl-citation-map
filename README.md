# Reinforcement-learning citation map

Interactive map of 55,590 reinforcement-learning papers and the citations among them,
grouped into citation communities. Open the site: https://ericgriessbach.github.io/rl-citation-map/

## Data and licences
- Paper metadata and citations come from [OpenAlex](https://openalex.org) (CC0).
- Abstracts are shown only when the paper's publisher version is openly licensed
  (CC BY, CC BY-SA, CC0 or public domain, as reported by OpenAlex), with attribution and
  a link to the licence. For all other papers the site links to the publisher's page.
  11,014 of 43,408 abstracts are shown.
- Abstract text is reconstructed by OpenAlex and its formatting may differ from the original.
